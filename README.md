# DrawAR

Una app Android para calcar imágenes sobre papel usando la cámara del dispositivo.

## ¿Qué hace?

DrawAR proyecta una imagen sobre la vista de la cámara para que puedas calcarla sobre una hoja física. Tiene dos modos:

**Normal** — Superpone la imagen directamente sobre la cámara. Puedes ajustar zoom, opacidad y posición para alinearla con tu hoja.

**Pro** — Usa Realidad Aumentada para detectar automáticamente la hoja y ajustar la imagen a sus dimensiones reales, facilitando un calcado más preciso.

## Requisitos

- Android 12 o superior (API 31+)
- Android Studio Ladybug o más reciente
- JDK 21


> El modo Pro requiere un dispositivo con soporte para ARCore.
